	Title Of The Project : “Online Shopping Websites”

This project is entitled Online Shopping Website. It is a web-based application that allows users to browse products, add them to a cart, and purchase items online. The system provides a user-friendly interface for customers to explore various product categories, view product details, and make secure payments.
This project is mainly developed using PHP and MySQL database. It has an attractive and responsive user interface with the help of Bootstrap framework. The system includes multiple features such as product search, cart management, order tracking, and user account management.

	OBJECTIVE OF THE PROJECT:

The Online Shopping Website has two main modules which are the User Site and the Admin Panel.
The User Site is accessible to all registered users. It allows customers to browse products, add items to their cart, and place orders. Users can also view their order history and manage their account details.
The Admin Panel is accessible only by the administrator. The administrator has full control over the system including product management, user management, and order processing. The admin can add, edit, or delete products and manage customer orders efficiently.
